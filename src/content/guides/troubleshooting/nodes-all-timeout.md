点测延迟，所有节点都显示 timeout 或 0ms，通常是以下几类原因。

## 先判断：是全部节点还是个别

- **个别节点超时** → 正常，换节点即可。
- **全部节点超时** → 多半是本地网络、订阅或时间问题，往下看。

## 1. 系统时间

时间不准会导致所有加密连接失败。**校准系统时间**（开启自动同步），这是最常见的坑。

## 2. 本地网络 / DNS

- 先确认 **不开代理能正常上国内网**。
- 切换网络（WiFi ↔ 流量）测试。
- DNS 被污染也会导致连不上，见 [DNS 泄露与异常](/guide/troubleshooting/dns-leak/)。

## 3. 订阅过期 / 机场异常

- 重新 [更新订阅](/guide/troubleshooting/subscription-update-failed/)。
- 机场流量跑完 / 到期 / 被封也会全超时，登录后台确认账号状态。

## 4. 客户端配置

- 关掉可能冲突的其它代理软件、VPN。
- 检查是否误开了某个导致回环的规则。
- 重启客户端 / 重启电脑。

## 5. 0ms 的特殊情况

延迟显示 0ms 往往是 **还没真正测速** 或测速被拦截，手动点「测试延迟」刷新；若刷新后仍 0ms 且连不上，按上面本地网络排查。

依然不行？可能是机场本身出问题了，换一家试试，或看机场 TG 群公告。
