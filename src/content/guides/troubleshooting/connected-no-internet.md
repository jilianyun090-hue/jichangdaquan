节点连上、延迟正常，网页却打不开，是典型的「连接通但流量没走对」。

## 1. 系统代理没开 / 开错

- 确认客户端的 **系统代理开关** 是打开的（不只是选了节点）。
- 用了 TUN 模式的，确认 TUN 正常工作。
- 有时系统代理和 TUN 同时开会冲突，二选一。

## 2. 代理模式不对

- 切到 **规则模式** 或 **全局模式** 试试。
- 规则集太旧可能把目标网站误判为直连，换新规则集。

## 3. DNS 问题

这是 TUN 模式下断网的最常见原因：

- 在客户端启用 **Clash DNS**（设置里打开 DNS 功能）。
- 确认没有被本地 hosts / 其它 DNS 软件干扰。
- 详见 [DNS 泄露与异常](/guide/troubleshooting/dns-leak/)。

## 4. TUN 模式专项

- 首次开 TUN 要装服务 / 给权限，没装成功会断网，重装一次。
- 虚拟网卡异常：关掉 TUN、重开，或重启客户端。
- 参考 [Clash TUN 模式详解](/guide/clients/clash-tun-mode/)。

## 5. 浏览器层面

- 换个浏览器排除缓存 / 扩展干扰。
- 关掉浏览器自带的「安全 DNS / DoH」后重试。

## 还是不行

关掉代理确认能上国内网 → 能，说明是代理配置问题，重新导入订阅、换节点；不能，先修本地网络。
