协议决定数据怎么伪装传输。你不用全懂，但知道区别有助于选客户端和排障。

## 常见协议一览

| 协议 | 特点 | 客户端支持 |
|---|---|---|
| **Shadowsocks (SS)** | 老牌、轻量、速度快，抗封锁一般 | 几乎全支持 |
| **VMess** | V2Ray 的协议，功能多，略重 | 广泛 |
| **VLESS** | VMess 的轻量继任者，常配 Reality / XTLS，抗封锁强 | 广泛 |
| **Trojan** | 伪装成正常 HTTPS 流量，隐蔽性好 | 广泛 |
| **Hysteria2** | 基于 QUIC/UDP，弱网和高丢包下速度好 | 较新客户端 |
| **TUIC** | 同样基于 QUIC，低延迟 | 较新客户端 |

## 实用结论

- **大多数情况**：机场给什么用什么，客户端能识别订阅里的协议，你不用手动选。
- **网络环境差、经常被限速** → 优先 Hysteria2 / TUIC 这类基于 UDP 的协议。
- **追求隐蔽、抗封锁** → VLESS + Reality 或 Trojan。
- **要兼容老设备 / 软路由** → SS 最通用。

## 和线路的关系

协议解决「怎么传」，[线路](/guide/concepts/route/) 解决「走哪条路」。两者都好，体验才好。自建时协议要自己选，见相关搭建教程。
