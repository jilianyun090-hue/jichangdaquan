线路类型是决定机场晚高峰稳不稳的核心因素。价格差异也主要来自这里。

## 两大类：公网 vs 专线

- **公网中转**：数据走公共互联网，成本低、价格便宜，但晚高峰拥堵时会卡。
- **专线（IEPL / IPLC）**：运营商的专用线路，不经过公网拥堵段，晚高峰也稳，但成本高、价格贵。

## 常见线路类型

| 线路 | 类型 | 特点 |
|---|---|---|
| **IEPL** | 专线 | 国际以太网专线，跨境不过公网墙，最稳，贵 |
| **IPLC** | 专线 | 国际私用租赁线路，同样绕开公网，稳 |
| **CN2 GIA** | 优质公网 | 电信精品网，公网里最好的之一，性价比高 |
| **CN2 GT** | 公网 | 比 GIA 低一档，晚高峰一般 |
| **BGP** | 公网 | 多线智能路由，常见、便宜 |
| **普通中转** | 公网 | 境内服务器中转到境外，价格低，质量看运营商 |

## 怎么选

- **追求晚高峰稳定、预算充足** → IEPL / IPLC 专线机场。
- **性价比党** → CN2 GIA。
- **只是偶尔用 / 备用** → BGP 或普通中转足够。
