有了机场，访问 Google 全家桶和 YouTube 是最基础的需求。

## 基本步骤

1. 按 [入门教程](/guide/getting-started/quickstart/) 装好客户端、导入订阅。
2. 选一个延迟低的节点，开启 **规则模式**。
3. 浏览器打开 google.com / youtube.com，正常使用。

## 看 YouTube 的优化

- **看 4K / 8K**：选带宽足的节点，优先专线或 CN2 GIA 线路。
- **YouTube Premium（去广告/后台播放）**：需要节点所在地区支持，部分地区价格更便宜，见 [流媒体解锁](/guide/streaming/youtube/)。
- 卡顿先降清晰度测试，再换节点，参考 [测速指南](/guide/concepts/speedtest/)。

## 访问不了怎么办

- **搜索出现验证码 / 被限制**：换一个更干净的节点（共享节点被滥用会触发风控）。
- **能连但打不开**：见 [连上但打不开网页](/guide/troubleshooting/connected-no-internet/)。
- **部分地区打不开**：换节点地区，优先香港 / 日本 / 新加坡等近距离节点。

## 浏览器小贴士

- 建议用 Chrome / Edge / Firefox，避免国产浏览器劫持。
- 装个能看当前出口 IP 的扩展，方便确认走没走代理。
